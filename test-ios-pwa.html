5. Installation Instructions

For iOS (Safari):

  1. Open this site in Safari on iPhone/iPad
  2. Tap the Share button (square with arrow)
  3. Scroll down and tap "Add to Home Screen"
  4. Tap "Add" in the top right

For Desktop (Chrome/Edge):

  1. Look for the install icon in the address bar
  2. Or go to menu → "Install CRM Application"

6. Capacitor Instructions

To build as a native iOS app using Capacitor:

npm install
npx cap add ios
npx cap sync ios
npx cap open ios

See CAPACITOR_GUIDE.md for detailed instructions.
